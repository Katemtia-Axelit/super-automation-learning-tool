# P1-5 状态评估与计时器说明

## 1. 真实接口清单（以当前代码为准）

### 状态评估

| 接口 | 说明 |
|------|------|
| `GET /api/state/questions` | 6 道问卷 + 1–5 分刻度 |
| `GET /api/state/assessment` | 今日评估；未完成时含 `questions` |
| `POST /api/state/assessment` | 提交 `{answers: {cognitive, focus, ...}}`，返回 energy/focus/mood/daily_tone |
| `GET /api/state/assessment/history?days=7` | 历史简表 |

后端无 stress、notes 字段；分数由公式计算，非手填。

### 计时器

| 接口 | 说明 |
|------|------|
| `GET /api/timer/active` | 当前进行中会话或 `null` |
| `POST /api/timer/start` | `{task_id, planned_minutes}` **必填 task_id** |
| `POST /api/timer/complete` | `{session_id, actual_minutes, result, reason}` |

**无** pause/stop 分离接口；**无** sessions/history 列表接口。

## 2. 前端接入

| 功能 | 位置 |
|------|------|
| 今日状态评估 | 日程页 `#stateAssessmentPanel` + Modal |
| 计时器 | 任务页 `#timerPanel`（选任务、开始、停止） |

# 本地启动说明（Windows）

## 前置条件

- 安装 **Python 3.10+**（https://www.python.org/downloads/）
- 安装时勾选 **Add python.exe to PATH**
- 若 `python --version` 无输出但弹出 Microsoft Store：在 Windows 设置 → 应用 → 应用执行别名 中关闭 `python.exe` / `python3.exe` 别名，或安装后使用 `py -3`

## 推荐启动方式（安全，不会误杀其他 Python 进程）

1. 双击项目根目录 **`启动学习工具.bat`**
2. 或运行 **`scripts\start_web_safe.bat`**

脚本会自动：

- 创建/使用项目内 **`.venv`**
- 安装 **`requirements-web.txt`**（仅 Flask，不含 PySide6）
- 启动 **`server/backend_api.py`**
- 健康检查通过后打开 **http://127.0.0.1:5000**
- 按任意键后 **仅停止本项目 PID**（写入 `.run/server.pid`）

## 停止服务

```bat
scripts\stop_web_safe.bat
```

## 手动启动（开发）

```bat
.venv\Scripts\python.exe -m pip install -r requirements-web.txt
.venv\Scripts\python.exe server\backend_api.py
```

## 验收脚本

```bat
.venv\Scripts\python.exe scripts\inspect_db_schema.py
.venv\Scripts\python.exe scripts\p0_test_deps.py
REM 服务器运行中：
.venv\Scripts\python.exe scripts\p0_acceptance_http.py
```

## 日志

- 服务日志：`.run/server.log`
- 进程 PID：`.run/server.pid`

## 桌面端（可选）

需要 PySide6 时使用：

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt
scripts\start-desktop.bat
```

## 常见问题

| 现象 | 处理 |
|------|------|
| Python not found | 安装 Python 并加入 PATH |
| WindowsApps python | 关闭应用别名或改用 py -3 |
| 端口占用 | 修改 `config/config.json` 中 `server.port` |
| 日程保存失败 | 确认已用新版 backend（使用 `user_schedule` / `daily_schedules` 表） |

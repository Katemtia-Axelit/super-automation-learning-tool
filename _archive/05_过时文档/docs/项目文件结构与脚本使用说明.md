## 1. 根目录

| 文件/目录 | 说明 |
|-----------|------|
| `index.html` | 前端唯一 HTML 入口；样式在 `<style>` 块；业务 JS 通过 `/static/app.js` 引入 |
| `config/config.json` | 端口、数据库路径、vault 路径、API Key 占位（**勿写绝对路径**） |
| `README.md` | 项目 5 分钟入口 |
| `启动学习工具.bat` | 一键调用 `scripts\start_web_safe.bat` |
| `requirements-web.txt` | Web 版 Python 依赖（Flask 等） |
| `data/` | SQLite 数据库目录 |
| `static/` | 前端静态资源 |
| `server/` | Flask 后端 |
| `scripts/` | 启停、备份、验收、导出脚本 |
| `docs/` | 文档 |
| `ai_workspace/` | 外部 AI 协作缓冲区（**不接自动写入**） |
| `src/notes/` | vault、prompts、raw 笔记材料 |

---

## 2. static/

| 文件 | 说明 |
|------|------|
| `static/app.js` | **唯一业务逻辑脚本**：导航、抽卡、任务、日程、反馈 Modal、计时器、智能体只读等 |

**为什么主要在 app.js**：P0 起约定单脚本架构，避免 `index.html` 内联 JS 难以维护。

**`app.js?v=13`**：URL 版本参数，改 JS 后 bump 版本可强制浏览器刷新缓存。

**禁止**：恢复旧的大段内联 JS；新增 Vue/React/Vite。

---

## 3. server/

| 文件 | 说明 |
|------|------|
| `server/backend_api.py` | Flask API：任务 CRUD、抽卡、日程、计时器、状态评估、提示词、弃牌堆、task_feedback、Agent 只读 GET 等 |

**不要随便改的区域**：

- 抽卡权重 / 算法（`GachaEngine` 等）
- `task_feedback_events` 表结构与写入逻辑（P1-5B 已锁定）
- Agent 只读 GET 以外的 process/save-note/import 行为

---

## 4. data/

| 文件 | 说明 |
|------|------|
| `data/task_publisher.db` | SQLite：**任务、标签、依赖、日程、计时、反馈、抽卡记录**等 |

- **不能删除**：这是全部用户学习数据
- **备份必须包含**：`backup_user_data.bat` 会复制此文件
- 不要用外部工具直接改表；封版期用 UI 或「导出 → AI 草稿 → 人工改 UI」

---

## 5. src/notes/

| 目录 | 说明 |
|------|------|
| `src/notes/vault/` | 知识库 Markdown（网页「知识库」Tab） |
| `src/notes/prompts/` | Agent 提示词（设置页可读可写，带备份/恢复） |
| `src/notes/未分类/` | Raw 转写/原始材料（Agent 只读 Tab「Raw」） |
| `src/notes/已分类/` | 已整理 raw 材料 |

**与 P1-6 关系**：设置 → 智能体只读浏览，可 GET 查看 prompts / vault / raw，**不执行、不写入**。

---

## 6. ai_workspace/

人工协作缓冲区，**无自动写入后端**。

| 目录 | 用途 |
|------|------|
| `00_context/` | `export_tasks_for_ai.py` 导出的任务快照 `.json` / `.md` |
| `01_requests/` | 你写给网页端 AI 的需求 |
| `02_ai_outputs/` | AI 原始回复存档 |
| `03_task_drafts/` | `task_patch.json` 草稿（含 `task_patch.example.json` 模板） |
| `04_reviewed/` | 人工确认后的版本 |
| `99_archive/` | 历史归档 |
| `README.md` | 目录说明 |

## 7. scripts/ 脚本说明

### 运维 / 封版

| 脚本 | 用途 | 何时运行 | 失败说明 |
|------|------|----------|----------|
| `start_web_safe.bat` | 创建/使用 .venv、装依赖、启动服务、health 检查、开浏览器 | 日常启动 | Python/依赖/端口问题 |
| `stop_web_safe.bat` | 停止服务、清理 PID | 日常停止 | 一般可忽略 NO_PID_FILE |
| `launch_server.py` | 被 start 调用，写 PID 与日志 | 一般不直接跑 | 见 server.log |
| `stop_server.py` | 端口清理辅助 | stop 时调用 | — |
| `check_portability.py` | 绝对路径扫描、关键文件、config 相对路径 | 换电脑/封版前 | 存在写死路径或缺文件 |
| `backup_user_data.bat` | 备份 db/vault/prompts/config | 离开电脑前、大改前 | 源文件缺失会 WARN |
| `verify_transferred_project.bat` | 新电脑：Python/.venv/db/health | 换电脑后 | 需重建 .venv |
| `run_stable_acceptance.bat` | 一键全量封版验收 | 开发回归 / 一周后继续开发前 | 某一 acceptance 失败 |

### 外部 AI 协作（只读 / 只校验）

| 脚本 | 用途 | 何时运行 | 失败说明 |
|------|------|----------|----------|
| `export_tasks_for_ai.py` | **只读**导出任务快照到 `ai_workspace/00_context/` | 要用网页 AI 改任务前 | 数据库不存在 |
| `validate_task_patch.py` | **只校验** `task_patch.json`，不写库 | AI 给出草稿后 | JSON 格式/字段/禁止项 |

### 质量 / 验收

| 脚本 | 用途 |
|------|------|
| `inspect_db_schema.py` | 检查数据库表结构是否完整 |
| `p0_test_deps.py` | 任务依赖逻辑单元测试 |
| `p0_acceptance_http.py` | P0 HTTP：health、日程、依赖、抽卡 |
| `p1_acceptance_existing_backend.py` | 计时器、状态、提示词、Agent GET 等 |
| `p1_2_acceptance_prompt_sleep.py` | 提示词只读 + 睡眠 API |
| `p1_2_e2e_prompt_sleep.py` | 上述 Playwright E2E |
| `p1_3_acceptance_prompt_activity.py` | 提示词可写 + 活动 CRUD |
| `p1_3_e2e_prompt_activity.py` | E2E（隔离测试提示词 `__TEST__P1_3_E2E.md`） |
| `p1_4_acceptance_discard_pile.py` | 弃牌堆 HTTP |
| `p1_4_e2e_discard_pile.py` | 弃牌堆 E2E |
| `p1_5_acceptance_state_timer.py` | 状态评估 + 计时器 HTTP |
| `p1_5_e2e_state_timer.py` | 状态评估 + 计时器 E2E |
| `p1_5b_acceptance_task_feedback.py` | 任务事件反馈 HTTP |
| `p1_5b_e2e_task_feedback.py` | 反馈 Modal E2E |
| `p1_6_acceptance_agent_readonly.py` | 智能体只读 HTTP |
| `p1_6_e2e_agent_readonly.py` | 只读 E2E（禁止 process/import） |
| `p1_visual_1_acceptance_card_ui.py` | 卡牌 UI 主链路 HTTP |
| `p1_visual_1_e2e_card_ui.py` | 卡牌 UI E2E |

### 全量回归手动命令

```bat
.venv\Scripts\python.exe scripts\inspect_db_schema.py
.venv\Scripts\python.exe scripts\check_portability.py
.venv\Scripts\python.exe scripts\export_tasks_for_ai.py
.venv\Scripts\python.exe scripts\validate_task_patch.py
scripts\run_stable_acceptance.bat
```

# 项目逻辑与阶段交接说明

说明**产品逻辑**和**开发阶段逻辑**，供新对话 / 一周后继续开发时快速接手。

---

## 1. 项目定位

- **不是**普通 Todo / 表格待办
- **不是**简单随机抽卡小游戏
- **是**个人超级自动化学习工具雏形：用「任务池 + 抽卡仪式感 + 执行反馈 + 知识/Agent 资产」推动真实学习行为

---

## 2. 当前核心闭环

```
任务池 → 抽卡（牌堆/翻牌）→ 执行（计时可选）
  → 完成 / 跳过 / 拒绝 / 弃牌
  → P1-5B 事件反馈（记录原因，不阻塞主流程）
  → 弃牌堆可恢复
  → 日程页状态评估
  → 设置页提示词管理 + Agent 只读浏览
```

用户感知关键词：**想抽一张、卡牌有主题、完成有收走感、弃牌有去向、跳过要说明原因**。

---

## 3. 关键数据关系

| 实体 | 存储 | 关系 |
|------|------|------|
| `tasks` | SQLite | 核心任务；含 category、priority、repeat、completed、in_discard_pile、prerequisite_ids |
| `task_dependencies` / `prerequisite_ids` | SQLite | 前置依赖；未完成则阻塞 |
| 弃牌堆 | `tasks.in_discard_pile` | 非删除；可 RESTore |
| `timer_sessions` | SQLite | 计时记录；结束可选反馈 |
| `task_feedback_events` | SQLite | P1-5B 跳过/弃牌/计时等**原因记录** |
| `prompts` | `src/notes/prompts/*.md` | Agent 提示词；可备份恢复 |
| vault / raw | `src/notes/vault/`、`未分类/`、`已分类/` | 知识库与原始材料；Agent 只读浏览 |

---

## 4. P1-5B 设计原则（已锁定）

- 反馈 **不阻塞** 主流程（取消 Modal 仍继续 skip/refuse 等）
- **只记录原因**，不自动改任务内容
- **不**自动改 `estimated_time`
- **不**自动改抽卡权重
- **不**自动拆任务 / 合并任务
- 表结构 `task_feedback_events` 勿随意改

---

## 5. P1-6 设计原则（已锁定）

- Agent **只读**浏览
- 前端只允许 **GET**（agents、prompt、raw/vault 文件内容）
- **禁止** `/api/agent/process`
- **禁止** save-note 写入 vault
- **禁止** import-tasks
- 不在只读模式改 prompts（改提示词走设置页 P1-3 流程）

---

## 6. P1-Visual-1 / 1A 设计原则

- **不是**美术资源 / 卡牌收藏 / 商城系统
- **是**任务执行**仪式感**：牌堆、卡背、边框、纹理、翻牌、完成蒸发、弃牌飞向
- 8 套 CSS 主题按标签/学科自动映射
- **不接** AI 图像生成
- 不改抽卡算法

---

## 7. 为什么暂不进入 P1-7

- 用户即将离开开发环境，**优先稳定使用一周**
- Agent **执行**涉及 vault 写入、任务导入等**高风险**
- 需要先做 **P1-7A 弱模型鲁棒性底座**，再做 **P1-7B 受控执行草稿模式**
- 封版期用 **外部网页 AI + ai_workspace + 人工 UI 修改** 代替自动执行

---

## 8. 当前 Agent 未内置执行时的外部 AI 协作方案

| 层 | 做什么 |
|----|--------|
| 本地导出 | `export_tasks_for_ai.py` 只读快照 |
| 网页 AI | 生成 `task_patch.json` + `task_change_summary.md` |
| 本地校验 | `validate_task_patch.py` 只校验格式与红线 |
| 人工 | 网页任务编辑 UI 逐条改 |
| 备份 | `backup_user_data.bat` |

**后续 P1-7A/7B** 才考虑在系统内受控执行草稿（仍要人工确认）。

详见：[外部AI协作与任务修改流程.md](外部AI协作与任务修改流程.md)

## 10. 项目红线

- 不引入 Vue / React / Vite
- 不恢复旧内联 JS
- 不删除 `data/task_publisher.db`
- 不让 Agent 直接写 vault
- 不让 Agent 直接 import tasks
- 不自动改抽卡权重
- 不破坏 `task_feedback_events`
- 不跳过人工确认做自动化写入

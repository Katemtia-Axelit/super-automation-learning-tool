# P1-2 提示词与睡眠追踪接入说明

## 1. 本轮接入范围

在 **不新增顶部导航 Tab** 的前提下，接入两项低风险前端能力：

| 功能 | 位置 | 模式 |
|------|------|------|
| 提示词文件浏览 | 设置页 `#promptPanel` | **只读**（GET 列表 + GET 内容 + 复制） |
| 睡眠追踪 | 日程页 `#sleepPanel` | 记录入睡时间 + 展示 streak + 近 7 日能量表格 |

## 2. 提示词编辑器为什么先做只读

1. 避免 Web 端误改 `src/notes/prompts/` 生产提示词。
2. 与智能体能力解耦，不依赖 API Key。
3. 为 P1-3「可写模式」预留 UI 结构与验收基线。

**本轮禁止调用：** `PUT /api/prompts/<name>`

## 3. 睡眠追踪当前支持能力

- 展示今日入睡时间、连续早睡天数（`sleep_early_streak`）
- `time` 输入 + 保存 → `POST /api/state/sleep`
- 近 7 日能量简表 → `GET /api/state/weekly-energy`

**本轮未做：** 早睡守护、睡前提醒、弹窗推送、图表库。

## 4. 本轮未接入的功能

- 智能体 UI（含 process / save-note / import-tasks）
- 知识图谱 Canvas
- 状态评估问卷
- 计时器 UI
- 提示词网页保存（PUT）

## 5. 验收脚本

| 脚本 | 说明 |
|------|------|
| `scripts/p1_2_acceptance_prompt_sleep.py` | HTTP：prompts GET、sleep POST/GET、weekly-energy |
| `scripts/p1_2_e2e_prompt_sleep.py` | Playwright：设置页提示词、日程页睡眠保存与刷新 |

运行前启动服务：`scripts/start_web_safe.bat`

回归脚本（须仍通过）：

- `scripts/p0_test_deps.py`
- `scripts/p0_acceptance_http.py`
- `scripts/p1_acceptance_existing_backend.py`

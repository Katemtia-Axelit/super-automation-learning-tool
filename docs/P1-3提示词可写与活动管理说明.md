# P1-3 提示词可写与活动管理说明

## 1. 本轮接入范围

| 功能 | 位置 | 能力 |
|------|------|------|
| 提示词可写 | 设置页 `#promptPanel` | 编辑模式、diff 预览、二次确认、PUT 保存、自动备份、恢复最近备份 |
| 活动管理 | 日程页 Modal `#activityMgrModal` | 活动列表、新增、删除（二次 confirm） |

**未新增导航 Tab。**

## 2. 提示词可写安全设计

- 文件名 **仅来自** `GET /api/prompts` 列表（前端 `data-idx` 索引）
- 后端 `_safe_prompt_basename()` 拦截：`..`、绝对路径、非 `.md`、隐藏文件、`.backups`
- 保存前写入 `src/notes/prompts/.backups/<文件名>.YYYYMMDD-HHMMSS.save.bak.md`
- 恢复前对当前文件再备份为 `...restore.bak.md`（与 save 备份区分，避免恢复时误选 restore 备份）
- 兼容旧格式 `*.bak.md`（无 save/restore 标记时按 mtime 取最新）
- 原子写入：先写 `.tmp` 再 `os.replace`
- **备份文件不出现在** `GET /api/prompts` 列表
- 不输出提示词完整内容到服务端日志

## 3. diff 预览说明

- 点击「预览修改」打开 `#promptDiffModal`
- 展示原/新字符数、新增/删除/修改行数摘要
- 逐行 diff（+ / - / ~），最多 80 行
- 「取消」关闭 Modal 不保存；「确认保存」才调用 PUT

## 4. 二次确认说明

- 取消编辑：内容有变时 `confirm` 放弃
- 保存：必须先预览 Modal 再确认
- 恢复备份：`confirm` 后 POST restore-latest

## 5. 备份与恢复 API

| 接口 | 说明 |
|------|------|
| `PUT /api/prompts/<name>` | 保存前自动备份，返回 `backup` 文件名 |
| `GET /api/prompts/<name>/backup/latest` | 是否存在最近备份 |
| `POST /api/prompts/<name>/restore-latest` | 用最近备份覆盖（覆盖前再备份当前） |

## 6. 活动管理 Modal

- `GET /api/schedule/activities` — 列表
- `POST /api/schedule/activities` — 新增（name 必填；type/duration 前端展示，DB 仅存 name）
- `DELETE /api/schedule/activities/<id>` — 删除

不影响日程 10 格 `daily_schedules` 逻辑。

# P1-4 弃牌堆浏览与恢复说明

## 1. 本轮接入范围

| 功能 | 位置 | 能力 |
|------|------|------|
| 弃牌堆浏览 | 任务页 `#discardPileOpenBtn` → `#discardPileModal` | 列表展示、单条恢复 |
| 单条恢复 | Modal 内「恢复」按钮 | confirm 后 POST restore，刷新列表与任务 |

**未新增导航 Tab。** 无批量恢复（后端无批量接口）。

## 2. 后端接口（以当前代码为准）

| 接口 | 说明 |
|------|------|
| `GET /api/discard-pile` | 弃牌堆任务列表（`in_discard_pile=1` 且未完成） |
| `POST /api/discard-pile/<id>/restore` | 单条恢复（`in_discard_pile=0`） |
| `POST /api/tasks/<id>/move-to-discard` | 移入弃牌堆（已有） |

无 `POST /api/discard-pile/restore-all` 等批量接口。

## 3. 列表字段

- id、name、repeat_type、tags
- status（弃牌堆 / 阻塞 / 可用 / 已完成）
- 弃牌时间：`last_completed_at`（移入时写入）或 `updated_at`

## 4. 前端交互

1. 任务页点击「查看弃牌堆」
2. Modal 加载 `GET /api/discard-pile`
3. 空列表显示「暂无弃牌任务」
4. 恢复：`confirm` → `POST restore` → toast → 刷新弃牌堆 + 任务列表 + 抽卡统计

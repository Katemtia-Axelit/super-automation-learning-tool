# P1-5B 任务事件反馈说明

## 背景

P1-5A 保留每日状态评估 + 计时器 UI。P1-5B 补齐**任务生命周期事件反馈**。

## 新增表 `task_feedback_events`

字段：task_id, event_type, planned_minutes, actual_minutes, completion_status, reason_category, reason_detail, note, created_at

## 新增接口

- `POST /api/task-feedback`
- `GET /api/task-feedback?task_id=<id>`

## 前端触发点

| 操作 | event_type |
|------|------------|
| 跳过 / 拒绝 | skip_task |
| 移入弃牌堆 | abandon_task |
| 计时完成且提前 ≥50% | finish_early |
| 计时完成且正常 | finish_on_time（静默记录） |
| 计时选「未完成」 | timer_timeout_unfinished |
| 计时选「放弃/中断」 | abandon_task |

## 与 timer_sessions

`/api/timer/complete` 仍写入 `timer_sessions.result/reason`；结构化反馈另存 `task_feedback_events`。

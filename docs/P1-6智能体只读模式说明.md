# P1-6 智能体只读模式说明

## 入口

设置页 `#agentReadonlyPanel` → 「打开智能体浏览」Modal（不新增顶部导航）。

## 只读 GET 接口

| 接口 | 用途 |
|------|------|
| GET /api/agent/agents | Agent 列表（含 input_type_label、action_labels） |
| GET /api/agent/agents/<id>/prompt | Agent 提示词全文（只读） |
| GET /api/agent/files/raw | Raw txt 目录列表 |
| GET /api/agent/files/raw/content?path= | Raw 文件内容 |
| GET /api/agent/files/vault | Vault md 目录列表 |
| GET /api/agent/files/vault/content?path= | Vault 文件内容 |
| GET /api/config | has_openai_key / has_claude_key 状态 |

## 禁止调用（本模式 UI 不触发）

- POST /api/agent/process
- POST /api/agent/save-note
- POST /api/agent/import-tasks
- PUT /api/prompts

## Agent 配置来源

`server/backend_api.py` 内 `AGENT_CONFIG`（5 个 Agent）；提示词来自 `src/notes/prompts/`。

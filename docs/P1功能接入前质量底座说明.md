# P1 功能接入前质量底座说明

## 1. 当前 P1 功能资产状态

P0 已通过：抽卡、任务、日程、知识库、设置五条 Web 主链路稳定运行。

P1-0 复盘结论：计时、状态评估、睡眠、提示词、智能体、知识图谱等能力 **后端 API 仍在**，但 Web 前端在精简回退时 **未保留入口**。桌面端（PySide6）仍保留部分能力（计时、早睡等）。

## 2. 为什么不能直接恢复旧前端

1. 旧版曾在 `index.html` 内联大段脚本，与 `static/app.js` 重复，导致重复声明、按钮无响应（P0-1 已修复）。
2. 知识图谱旧后端使用 **随机连边占位**，直接接 Canvas 会展示假数据。
3. 智能体涉及 **API Key、vault 写入、任务导入**，需分阶段只读接入。
4. 空库部署时 timer/assessment 表缺失会导致 500，必须先补齐 schema ensure。

**原则：新功能只扩展 `static/app.js` + 最小 DOM，禁止大段内联脚本回灌。**

## 4. P1-1 本轮 schema ensure

启动时（`backend_api.py` `__main__`）幂等调用：

- `ensure_timer_schema()` — 表 `timer_sessions`
- `ensure_assessment_schema()` — 表 `state_assessments`
- `ensure_daily_state_schema()` — 表 `daily_user_state`

规则：表不存在则 `CREATE TABLE IF NOT EXISTS`；字段缺失则 `ALTER TABLE ADD COLUMN`；不删表、不清数据。

字段与当前 API 读写一致，例如：

- timer：`started_at` / `ended_at` / `planned_minutes` / `actual_minutes` / `status` / `result` / `reason`
- assessment：`answers` / `energy_score` / `focus_score` / `mood_score` / `daily_tone` / `formula_version`
- daily_state：`energy_morning` / `energy_afternoon` / `energy_evening` / `bed_time` / `sleep_early_streak`

## 5. 知识图谱修复说明

`/api/knowledge/graph` 已改为：

1. 递归扫描 `src/notes/vault/` 下 `.md`（跳过 `.obsidian` 等隐藏目录）。
2. 每个文件一个 node：`id` / `title` / `path` / `category` / `tags`。
3. 解析 `[[双链]]`、`[[目标|别名]]`、`[文本](相对路径.md)`。
4. 链接目标能在 vault 中匹配时才生成 link（`type`: `wiki_link` 或 `markdown_link`）。
5. **不再使用 random 生成边**；无真实链接时 `links=[]`。

## 6. 测试 Banner 移除

`index.html` 顶部 `#testBanner` 已移除。`app.js` 中 `window.onerror` 改为 `console.error`，不再常驻页面提示。

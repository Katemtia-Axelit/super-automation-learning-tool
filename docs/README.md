# 🎓 超级自动化学习工具

> 用「AI笔记生产流水线 + 任务抽卡系统」逼迫你把时间花在真正的思考上。

**核心定位**：真正用在思考上的时间越多，学到的就越多。系统削减一切假努力的时间，让学习回归本质。

## 🚀 快速开始

### 1. 启动服务

```
双击 启动学习工具.bat
```

成功标志：浏览器自动打开 `http://127.0.0.1:5000/`

### 2. 快速操作

| 操作 | 说明 |
|------|------|
| 抽卡 | 点击「单抽」或「连抽」，从任务池抽取学习任务 |
| 完成任务 | 点击「开始任务」，使用计时器记录 |
| 浏览知识库 | 切换到「知识库」Tab，按学科浏览笔记 |
| 管理任务 | 切换到「任务」Tab，创建/编辑/删除任务 |

## 🧠 核心功能

### 1. AI笔记生产流水线

```
原始录音/字幕 → AI笔记整理师 → 结构化Markdown笔记
                                ↓
                    AI知识点整理师 → 独立知识点文件
                                ↓
                    AI内容审查师 + AI结构审查师 → 质检报告
```

### 2. 任务抽卡系统

- **3个卡池**：碎片(0-15min)、番茄(15-45min)、深度(45min+)
- **加权随机**：基于优先级、DDL紧迫度、精力匹配
- **换牌机制**：不满意可以选择换牌
- **弃牌堆**：拒绝的任务可随时恢复

### 3. 复习验证机制

- **笔记链**：按章节顺序复习笔记
- **习题链**：每节配习题验证理解
- **两条链互不阻塞**：可边复习笔记边做习题

## 📚 AI Agent提示词

四个Agent各司其职：

| Agent | 职责 |
|-------|------|
| **笔记整理师** | 将原始录音重构为结构化Markdown笔记 |
| **知识点整理师** | 从笔记中提取独立知识点文件 |
| **内容审查师** | 检查事实准确性、逻辑一致性、内容可读性 |
| **结构审查师** | 检查格式规范性、结构完整性、链接健康度 |

## ⚙️ 配置

配置文件位于 `config/config.json`：

```json
{
    "server": {
        "port": 5000,
        "host": "0.0.0.0"
    },
    "obsidian": {
        "vault_path": "src/notes/vault"
    },
    "database": {
        "task_db_path": "data/task_publisher.db"
    }
}
```

## 🔧 常见问题

| 问题 | 解决方案 |
|------|---------|
| 页面打不开 | 确认服务已启动，访问 `/api/health` 检查状态 |
| 端口被占用 | 修改 `config.json` 中 `server.port`，重启服务 |
| 抽不到任务 | 检查任务池是否有可用任务 |
| 笔记不显示 | 确认vault路径正确，检查浏览器控制台错误 |

## 📖 设计哲学

> **真正用在思考上的时间越多，学到的就越多。**

本系统旨在：
- 削减一切假努力的时间（手抄笔记、临时整理）
- 让用户把时间花在真正的思考上
- 用习题验证理解深度，而非用抄写假装学习

详见 [总体构思.md](总体构思.md)。

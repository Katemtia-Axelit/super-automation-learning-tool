## 修复范围（只做这些）
### P0-1: interval 未清理（bug 3.8）
- 现状：`initTimerDock()` 中每次调用 `loadTimerDockActive()` 都会 `setInterval`，无清理
- 要求：在创建新 interval 前先 `clearInterval(timerDockTick)`（或统一封装 start/stop）
- 判定标准：多次调用 initTimerDock 后，全局仅 1 个 interval 在跑（记录 interval ID 验证）

### P0-2: 提前结束状态不一致（bug 3.4）
- 现状：`stopTimerFromDock()` 中 confirm 后调 `/api/timer/complete` 传 `abandoned`，但任务本身未标记完成/跳过/弃牌堆，状态可能不一致
- 要求：明确 abandoned 的后续处理——任务保持"可用/未完成"状态（可重新开始），UI 提示"已中断"；若后端需要同步字段，先说明理由再改
- 判定标准：提前结束后，任务列表该任务状态正确（未完成、可重新计时），数据库 timer_sessions 该记录 result='abandoned' 且任务无脏数据

### P0-3: 抽卡动画状态机中断（bug 1.3）
- 现状：双 rAF 链未清理，页面切换时卡片可能停留在 `is-drawing`
- 要求：在 `showPage()` 切换时清理抽卡动画状态（或 `drawGacha()` 开头重置旧卡片状态）；确保切页后残留 DOM/CSS 类被移除
- 判定标准：动画进行中切页 → 切回后无残留 `.task-card.drawn-card`、无卡在 `is-drawing` 的卡片，牌堆动画正常

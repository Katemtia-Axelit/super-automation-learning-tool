# 一周稳定使用与换电脑迁移说明

面向**用户自己**的操作手册。当前为 **P1-Stable-1B 一周稳定使用封版**。

---

## 一、一周稳定使用前检查清单

离开开发环境 / 换电脑前，请确认：

- [ ] 已运行 `scripts\backup_user_data.bat`，且 `backups/` 下有新目录
- [ ] 服务可启动：`启动学习工具.bat` 或 `scripts\start_web_safe.bat`
- [ ] 浏览器能打开 `http://127.0.0.1:5000/`
- [ ] `http://127.0.0.1:5000/api/health` 返回 `"status":"healthy"`
- [ ] 抽卡、任务列表、日程、设置（智能体只读）均可正常打开
- [ ] 已阅读 [外部 AI 协作与任务修改流程](外部AI协作与任务修改流程.md)（如需改任务）

---

## 二、离开电脑前必须做什么

1. **停止服务**（可选但推荐）：`scripts\stop_web_safe.bat`
2. **备份用户数据**：`scripts\backup_user_data.bat`
3. **确认健康检查**：若服务仍在跑，访问 `/api/health`
4. **确认页面能打开**：至少打开一次首页
5. **确认备份目录存在**：`backups/YYYYMMDD-HHMM/` 内含 db、vault、prompts、config

---

## 三、日常启动

```bat
启动学习工具.bat
```

或：

```bat
scripts\start_web_safe.bat
```

成功标志：终端显示 `Health check OK`，浏览器自动打开。

---

## 四、日常停止

```bat
scripts\stop_web_safe.bat
```

若启动窗口仍开着，也可在窗口内按任意键停止。

---

## 五、日常备份

```bat
scripts\backup_user_data.bat
```

**建议频率**：

- 每天学习结束前（如有改任务）
- 用外部 AI 改任务前 / 后
- 换电脑前必做

---

## 六、如何恢复备份

1. `scripts\stop_web_safe.bat`
2. 从 `backups/某次备份/` 复制文件覆盖回项目对应路径：
   - `data/task_publisher.db`
   - `config/config.json`
   - `src/notes/vault/`
   - `src/notes/prompts/`
3. `启动学习工具.bat`

---

## 七、换电脑必须复制的内容

| 路径 | 说明 |
|------|------|
| `index.html` | 前端入口 |
| `static/` | 含 `app.js` 业务逻辑 |
| `server/` | Flask 后端 |
| `scripts/` | 启停、备份、验收、导出脚本 |
| `data/task_publisher.db` | **核心用户数据** |
| `config/config.json` | 配置（注意不是根目录 config.json） |
| `src/notes/vault/` | 知识库笔记 |
| `src/notes/prompts/` | Agent 提示词 |
| `src/notes/未分类/` | Raw 未分类材料（如有） |
| `src/notes/已分类/` | Raw 已分类材料（如有） |
| `requirements-web.txt` | Python 依赖 |
| `docs/` | 使用与交接文档 |
| `ai_workspace/` | 外部 AI 协作缓冲区（可选但建议） |
| `README.md` | 项目入口 |

**最简单做法**：复制整个项目文件夹（排除下面「可不复制」项）。

---

## 八、不建议依赖或可不复制的内容

| 路径 | 说明 |
|------|------|
| `.venv/` | **不保证跨设备可用**，新电脑必须重建 |
| `__pycache__/` | Python 缓存 |
| `.run/server.log` | 日志，可不带 |
| 临时 `__TEST__` 任务 | 验收残留，可删 |
| 旧 `backups/` | 按需复制最新一份即可 |

---

## 九、新电脑首次运行步骤

1. 安装 [Python 3.10+](https://www.python.org/downloads/)，勾选 **Add python.exe to PATH**
2. 进入项目根目录
3. 创建虚拟环境：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-web.txt
```

4. 可迁移性检查：

```bat
.venv\Scripts\python.exe scripts\check_portability.py
```

5. 迁移验证（含启动 + health）：

```bat
scripts\verify_transferred_project.bat
```

6. 日常使用：`启动学习工具.bat`

---

## 十、端口占用怎么办

1. `scripts\stop_web_safe.bat`
2. 仍占用则重启电脑，或修改 `config/config.json` 中 `server.port`
3. 重新启动

---

## 十一、页面打不开怎么办

- 确认终端有 `Health check OK`
- 手动访问 `http://127.0.0.1:5000/api/health`
- 查看 `.run\server.log` 最后几十行
- 确认防火墙未阻止本机 127.0.0.1

---

## 十二、/api/health 不通怎么办

- 服务未启动 → 运行 `启动学习工具.bat`
- 端口错误 → 检查 `config/config.json` 的 port
- Python 依赖缺失 → 重装 `requirements-web.txt`
- 后端崩溃 → 查 `.run\server.log`

---

## 十三、static/app.js 404 怎么办

- 确认 `static/app.js` 文件存在
- 确认 `index.html` 引用为 `/static/app.js?v=13`
- 确认从项目根目录启动服务（`launch_server.py` 会设 cwd）
- 硬刷新浏览器 Ctrl+F5

---

## 十四、数据库找不到怎么办

- 确认 `data/task_publisher.db` 存在
- 确认 `config/config.json` 中 `database.task_db_path` 为 `data/task_publisher.db`
- 从 `backups/` 恢复

---

## 十五、.venv 损坏怎么办

```bat
rmdir /s /q .venv
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-web.txt
```

不要从旧电脑复制 `.venv`。

---

## 十六、一周后回来继续开发前先跑哪些脚本

```bat
scripts\run_stable_acceptance.bat
```

或手动跑 P0～P1-Visual-1 全量回归（见 [项目文件结构与脚本使用说明](项目文件结构与脚本使用说明.md)）。

开发前先：`scripts\backup_user_data.bat`

---

## 十七、当前版本不需要做什么

- ❌ 不需要公网部署
- ❌ 不需要登录系统
- ❌ 不需要云同步
- ❌ 不需要 Agent 自动执行 / 自动写 vault / 自动 import tasks

---

## 十八、路径配置（迁移安全）

`config/config.json` 应使用相对路径：

```json
{
  "database": { "task_db_path": "data/task_publisher.db" },
  "notes_directory": "src/notes/vault",
  "vault_path": "src/notes/vault"
}
```

启动脚本基于 `%~dp0`，不写死本机绝对路径。

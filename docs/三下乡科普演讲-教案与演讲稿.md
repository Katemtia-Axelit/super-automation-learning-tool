# 教案：让AI不止会聊天 —— LLM·Agent·Workflow科普

> **适用对象**：初中生/高中生  
> **预计时长**：20-30分钟  
> **教学目标**：让听众理解什么是LLM、Agent、Workflow，以及如何给AI"接上手脚"

---

## 一、教学设计

### 1.1 引入：从"AI聊天"到"AI干活"

| 时间 | 内容 | 备注 |
|------|------|------|
| 0-3min | **开场互动**：问大家平时用什么AI？DeepSeek？豆包？ChatGPT？ | 引发共鸣 |
| 3-5min | **灵魂拷问**：它们能帮你整理笔记吗？能帮你做作业吗？ | 引出痛点 |

### 1.2 核心内容模块

#### 模块一：什么是LLM（大语言模型）—— 5分钟

**教学目标**：让听众理解AI"大脑"的本质

**类比教学**：
- LLM = 超级图书管理员
- 读过的书 = 训练数据
- 回答问题 = 图书管理员帮你找资料

**关键信息点**：
1. LLM是"超级大脑"，会聊天、写作、分析
2. 但它只能输出文字，不能帮你做实际的事
3. 就像一个很聪明但没有手脚的人

#### 模块二：什么是Agent（智能体）—— 8分钟

**教学目标**：让听众理解Agent = 大脑 + 手脚 + 工具

**类比教学**：
- Agent = 聪明的大学生 + 工牌 + 各种工具
- Prompt（提示词）= 工作手册/岗位说明书
- 工具 = 电脑、打印机、文件柜

**互动设计**：
> "如果我告诉你：DeepSeek可以帮你自动整理课堂笔记、生成学习任务、管理你的复习计划，你觉得它是怎么做到的？"

#### 模块三：什么是Workflow（工作流）—— 5分钟

**教学目标**：让听众理解多Agent协作

**类比教学**：
- Workflow = 流水线/分工合作
- 多个Agent = 流水线上的多个工人
- 每个工人只做一件事，但串联起来能完成复杂任务

**案例展示**（结合项目）：
```
原始笔记 → 笔记整理师(提取内容) → 知识点整理师(提炼知识点) → 结构审查师(检查结构) → 内容审查师(审核质量) → 结构化知识库
```

#### 模块四：Demo演示 —— 5-8分钟

**教学目标**：用实际案例展示Agent能力

**展示内容**：
1. 上传一段课堂笔记（或语音转写）
2. 展示多Agent如何协作处理
3. 展示最终生成的结构化笔记

**关键话术**：
> "这就是我做的学习工具。它背后的原理很简单：让不同的AI各司其职，串联起来工作。"

### 1.3 总结与升华

**回归主题**："让AI不止会聊天"

**核心要点回顾**：
1. LLM = 会思考的大脑
2. Agent = 大脑 + 能执行的手脚
3. Workflow = 多个Agent分工协作

**号召**：
> "今天你们学到了：AI不只是聊天工具，它可以成为你的学习助手、工作伙伴。关键是——给它接上合适的手脚。"

## 二、演讲稿大纲

### 开场（0-3分钟）

```
同学们好！

今天我想先问大家一个问题：你们平时用过AI吗？

（停顿，等回应）

DeepSeek？豆包？ChatGPT？

很好！看来大家对AI都不陌生。

但是我今天想问大家另一个问题——
```

### 第一部分：LLM是什么（3-8分钟）

```
大家有没有这种感觉：
有时候问DeepSeek一个问题，它回答得特别好，特别聪明。

但有时候你让它"帮我整理一下这周的笔记"，
它却只能给你一些建议，说"你可以这样做..."，
它自己没办法帮你整理。

为什么？

因为它只有一个"大脑"，没有"手脚"。
```

**【类比展开】**
```
想象一下：

LLM就像一个特别聪明的图书管理员。
它读过的书比我们一辈子读的都多。
你问它什么问题，它都能给你答案。

但如果你让它帮你整理书架——
它只能告诉你"你应该按这个顺序摆放"，
它自己没办法动手。

AI就是这样：
它很聪明，但如果你不给它工具，
它只能说话，不能干活。
```

### 第二部分：Agent是什么（8-16分钟）

```
那怎么让AI能干活呢？

答案很简单：给它接上手脚。

我们把一个LLM（大脑）和一些工具（手脚）组合在一起，
就变成了一个"Agent"——智能体。

【展示项目截图/架构图】

这就是我做的学习工具的一部分。

它里面有几个专门的"AI员工"：

第一个叫"笔记整理师"——
你给它一段乱七八糟的课堂笔记，
它能帮你整理成结构清晰的Markdown。

第二个叫"知识点整理师"——
它能从笔记里提取出核心知识点，
生成知识点卡片。

第三个叫"结构审查师"——
它检查整理好的笔记结构是否完整。

第四个叫"内容审查师"——
它检查知识点是否准确。

这就像一个知识加工工厂：
原材料进来，不同的工人各司其职，最终产出高质量的知识产品。
```

### 第三部分：Workflow是什么（16-21分钟）

```
有人可能会问：为什么要这么多人？

这就是Workflow（工作流）的魅力。

一个复杂的任务，单个AI很难做好。
但如果把它拆成多个步骤，交给不同的Agent，
每个Agent只专注做一件事，
串联起来就能完成非常复杂的任务。

【展示Workflow流程图】

这就是我们的工作流：

原始笔记 
→ 笔记整理师（提取、重构）
→ 知识点整理师（提炼核心）
→ 结构审查师（检查完整性）
→ 内容审查师（审核准确性）
→ 最终输出（结构化知识库）

每个Agent只做一件事，但组合起来，
它能做的事情，远超任何一个单一AI。
```

### 第四部分：Demo演示（21-26分钟）

```
说了这么多，可能还是有点抽象。
让我给大家演示一下实际效果。

【演示环节】

这是我今天早上随手写的一段课堂笔记——
（展示原始内容）

我们把它交给AI处理...
（展示处理过程）

看看结果：
（展示整理后的结构化笔记）

从一段乱七八糟的文字，变成了一张张清晰的知识卡片。
这个过程，就是由多个Agent协作完成的。
```

### 结尾（26-30分钟）

```
同学们，今天我们学到了什么？

第一，LLM（大型语言模型）是AI的大脑，
它很聪明，但只会说话。

第二，Agent（智能体）是AI的大脑加上手脚，
有了工具，它就能干活。

第三，Workflow（工作流）是多个Agent分工协作，
一个人做不完的事，团队可以完成。

所以，回到我今天演讲的主题——

"让AI不止会聊天"

AI不只是你手机里那个会回答问题的工具。
给它接上手脚，它可以成为你的学习助手、工作伙伴。

谢谢大家！
```

## 三、PPT修改建议

### 3.1 整体结构调整

| 建议 | 理由 |
|------|------|
| 增加"互动页" | 每讲完一个概念插入1-2张互动页，避免纯文字轰炸 |
| 减少代码/技术细节 | 面向初中生，技术细节点到为止 |
| 增加类比图示 | 用生活化图示代替抽象概念 |
| 预留Demo截图位置 | 演讲时需要展示实际效果 |

### 3.2 具体页面建议

#### 建议新增的页面

| 页面内容 | 位置 | 说明 |
|---------|------|------|
| 灵魂拷问页 | 开场 | "它们能帮你整理笔记吗？" |
| LLM类比图 | LLM讲解时 | 图书管理员图示 |
| Agent架构图 | Agent讲解时 | 大脑+工具的组合图 |
| Workflow流程图 | Workflow讲解时 | 流水线分工图 |
| Before/After对比 | Demo前 | 原始笔记 vs 整理后笔记 |
| 总结回顾页 | 结尾 | 三点核心收获 |

#### 建议精简的内容

| 原页面 | 建议处理 |
|--------|---------|
| 多Agent详细说明 | 简化为"流水线分工"概念 |
| 数据库/API等技术术语 | 删除或一笔带过 |
| 代码示例 | 删除（不适合初中生） |
| 项目复杂架构图 | 只展示核心Workflow即可 |

### 3.3 视觉风格建议

| 元素 | 建议 |
|------|------|
| 配色 | 保持简洁，用2-3种主色即可 |
| 字体 | 标题大、正文清晰，避免过多文字 |
| 图示 | 多用图标、流程图，少用文字描述 |
| 互动 | 每5分钟插入一个问题或思考题 |

## 四、备选互动问题

1. **开场**："你们用AI做什么？聊天？搜题？写作文？"
2. **LLM后**："如果AI只能说话不能干活，它像什么？"
3. **Agent后**："如果给你一个Agent，你最想让它帮你做什么？"
4. **Workflow后**："为什么流水线比一个人做所有事更高效？"

## 五、演讲注意事项

### 5.1 时间把控

| 模块 | 建议时长 | 备选内容 |
|------|---------|---------|
| 开场互动 | 3分钟 | 可压缩至2分钟 |
| LLM讲解 | 5分钟 | 可压缩至3分钟 |
| Agent讲解 | 8分钟 | 核心模块，不建议压缩 |
| Workflow讲解 | 5分钟 | 可与Agent合并 |
| Demo演示 | 5分钟 | 视情况可跳过 |
| 结尾总结 | 2分钟 | 必须保留 |

### 5.2 关键话术

- **类比要贯穿始终**：图书管理员、流水线工人、大脑与手脚
- **用"我们"不用"你"**：拉近距离，"我们一起看看"
- **留白与停顿**：每讲完一个概念，稍作停顿，让听众消化
- **用问题引导思考**：不要只陈述，要多提问

### 5.3 突发情况预案

| 情况 | 应对 |
|------|------|
| Demo无法演示 | 提前准备截图/视频作为备份 |
| 时间不够 | 跳过Demo，保留结尾总结 |
| 听众反应冷淡 | 增加互动问题，活跃气氛 |
| 技术术语听不懂 | 立即用类比重新解释 |

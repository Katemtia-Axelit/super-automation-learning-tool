============================================
          学习工具 - 使用说明 (整合版)
============================================

一、文件结构说明：
经过整合后，文件按功能分类存放：

├── index.html              # 前端主页面（启动后自动打开）
├── 启动学习工具.bat        # 一键启动（双击即可）
│
├── server/                 # 后端服务
│   └── backend_api.py      # Flask后端API
│
├── config/                 # 配置文件
│   └── config.json         # 统一配置（端口、API Key、路径等）
│
├── tools/                  # 工具脚本
│   └── migrate_data.py     # 数据迁移工具
│
├── docs/                   # 文档说明
│   ├── README.md           # 详细文档
│   └── 使用说明.txt         # 本文件
│
├── tools/                  # 工具脚本
│
├── 任务发布系统/           # 原系统（不动）
└── 笔记处理系统/           # 原系统（不动）

二、启动方法：
双击运行 "启动学习工具.bat"（在根目录下）

三、功能介绍：
🎲 抽卡页面：抽取学习任务
   - 选择精力状态（低/中/高）
   - 选择卡池（碎片/番茄/深度）
   - 点击圆形按钮抽卡
   - 可完成、跳过或拒绝任务

📋 任务页面：查看所有任务列表

📚 知识库：浏览笔记和知识点
   - 笔记列表：按学科分类展示
   - 知识点分类：点击展开查看
   - 点击笔记右侧🔗按钮在Obsidian中打开

🤖 AI助手：智能问答功能

📅 日程：查看学习日程安排

⚙️ 设置：配置端口、API密钥、Obsidian路径等

四、配置文件位置：
config/config.json
可修改：端口、笔记目录路径、API密钥、Obsidian路径

五、注意事项：
- 启动脚本会自动安装所需依赖
- 数据保存在 任务发布系统/data/task_publisher.db
- 关闭命令行窗口即停止服务
- 原系统文件未被修改，仍可独立使用

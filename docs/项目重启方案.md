## 三、依赖版本升级指南

### 3.1 当前依赖 vs 推荐版本

| 包名 | 当前要求 | 推荐版本 | 升级说明 | 风险等级 |
|------|----------|----------|----------|----------|
| **flask** | >=2.0 | **3.1.0** | Flask 3.x 完全兼容，去除 deprecated warning | 低 |
| **flask-cors** | (未指定) | **5.0.0** | 兼容 Flask 3.x | 低 |
| **PySide6** | >=6.5.0 | **6.8.0** | Qt 6.8 LTS，更好的 Windows 支持 | 中 |
| **werkzeug** | (flask 依赖) | **3.1.0** | Flask 3.x 配套 | 低 |

### 3.2 requirements-web.txt 推荐内容

```txt
# Web 服务器依赖（Flask）
flask>=3.0.0
flask-cors>=5.0.0
werkzeug>=3.1.0

# 可选：异步任务（未来扩展）
# celery>=5.4.0
# redis>=5.2.0

# 可选：更好的开发体验
# flask-debugtoolbar>=1.0.0
```

### 3.3 requirements.txt 推荐内容

```txt
# 核心依赖
flask>=3.0.0
flask-cors>=5.0.0

# 桌面 GUI（可选）
PySide6>=6.8.0

# 数据处理（可选扩展）
# pillow>=11.0.0  # 图片处理
# openpyxl>=3.1.0  # Excel 支持
```

### 3.4 升级步骤

```bash
# 1. 备份当前环境
.venv\Scripts\python.exe -m pip freeze > requirements_backup.txt

# 2. 删除旧虚拟环境
rmdir /s /q .venv

# 3. 重建虚拟环境
py -3 -m venv .venv

# 4. 安装新依赖
.venv\Scripts\python.exe -m pip install -r requirements-web.txt

# 5. 验证安装
.venv\Scripts\python.exe -m pip list
```
